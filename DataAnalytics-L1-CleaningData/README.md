# Oasis Infobyte Internship — Task 03: Cleaning Data

## Objective
To identify and handle missing values, duplicate records, inconsistent formatting, incorrect data types, and potential outliers in a dataset.

## Dataset
- Dataset: Titanic passenger dataset
- Original file: `tested.csv`
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab

## Work Completed
- Loaded and inspected the dataset.
- Generated a data-quality report.
- Checked missing values and duplicate records.
- Handled missing values in Age, Fare, and Cabin.
- Standardized text formatting.
- Corrected data types.
- Detected potential outliers using the IQR method.
- Created a before-and-after cleaning summary.
- Exported the cleaned dataset to CSV.

## Files
- `Oasis_Infobyte_L1_task_03.ipynb` — Jupyter notebook containing the code and analysis.
- `Titanic_Cleaned.csv` — cleaned dataset.

## Conclusion
The dataset was cleaned and validated using Python libraries. Cleaning decisions were documented, and the resulting CSV was saved for further analysis.
