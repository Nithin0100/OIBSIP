# Customer Segmentation Analysis

## Oasis Infobyte Internship — Data Analytics
**Task:** Level 1 — Task 02

## Objective
To segment customers of an e-commerce business based on their purchasing behaviour using RFM analysis and K-Means clustering.

## Dataset
The project uses the Online Retail dataset, which contains transaction details such as invoice numbers, product descriptions, quantities, invoice dates, unit prices, customer IDs, and countries.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- K-Means Clustering
- StandardScaler

## Methodology
1. Loaded and inspected the dataset.
2. Cleaned missing values, duplicate records, cancelled transactions, and invalid quantities or prices.
3. Calculated customer Recency, Frequency, and Monetary values (RFM).
4. Standardized the selected features.
5. Used the Elbow Method to help select the number of clusters.
6. Applied K-Means clustering.
7. Visualized customer clusters and compared their characteristics.
8. Developed customer profiles and marketing recommendations.

## Project Files
- `Oasis_Infobyte_L1_task_02.ipynb` — Analysis and clustering notebook.
- `Customer_Segmentation_Results.csv` — Customer-level segmentation results.
- `Customer_Segment_Profile.csv` — Summary of customer segments.

## Outcome
The analysis groups customers according to their purchasing behaviour and provides insights that can support targeted marketing, customer retention, and customer engagement strategies.
